This casebook applies existing LUMINA-30 boundary-review concepts to real-world high-impact irreversibility cases. It is not an official standard, certification, safety guarantee or legal determination.

## Millennium Project connection

This casebook is a T1000-C-centered operational validation layer. It separates Case Type from Empirical Status and Applicability Status, preserves falsifiability and negative evidence, and can feed validated results toward T1000-F, T1000-G and T1000-H. It is not a new core theory and does not establish "Irreversibility Boundary Theory" as canon.

Portable questions:
- Where is the irreversible boundary?
- Before it, can humans still effectively refuse, stop, verify, or redirect?
